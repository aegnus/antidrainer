Fetching sites

Local helperNot running. Start it with python3 drainer-bench.py

Browsers don't let one page read another site. The local helper fetches sites from your own computer. Without it, the bench tries a direct request and then free public relays (allorigins.win, codetabs.com), which often fail and see the address you test. A relay prefix gets the site address added to the end.

Limits of this test

Without the local helper, browsers block reading other sites, so most sites won't load. Open the bench through python3 drainer-bench.py.
The site runs at a local test address, so sites that check their own address or block unknown visitors may behave differently. The code scan still checks every script file the site loads.
Kits can hide when they detect a sandbox, a relay, a fake wallet or an empty balance. A clean result means "nothing seen", not "safe".
Drainers also abuse your real wallet's genuine prompts. Always read the request in your wallet's own window before signing.
